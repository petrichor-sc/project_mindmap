# Project Mind Map

An immersive, interactive 3D workspace designed to visualize, organize, and connect multiple research projects within a shared knowledge universe.

Built with **Three.js and GSAP**, Project Mind Map transforms traditional project management into a navigable environment featuring animated 3D structures, interconnected knowledge nodes, and portals between projects.

### Key Features
- **Interactive 3D visualization** with orbit controls, zoom, animated navigation, and guided tours.
- **Connected project universes** linking research topics, publications, tasks, milestones, and decisions.
- **Cross-project portals** to explore relationships and shared concepts between research activities.
- **Knowledge management** with editable entries, notes, references, and relationship mapping.
- **Customizable workspaces** supporting multiple projects and organizational structures.
- **Local data persistence** with workspace import/export functionality.
- **Responsive interface** with WebGL rendering and an interactive 2D fallback.

### Research Integration
Initially developed to connect four interdisciplinary research activities:

- Olfactory VR Thesis
- IP11 – Multisensory Mixed Reality Learning Station
- IP12 – Industry 5.0
- Interreg – Intercultural Olfactory Workshops

### Technology
**Three.js · GSAP · JavaScript · HTML · CSS · WebGL**

Project Mind Map explores a more spatial and intuitive approach to research organization, replacing isolated documents and conventional mind maps with an interconnected, navigable knowledge environment.
